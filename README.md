# Quantarys White Labels Ecommerce

Este repositório contém dois modelos de ecommerce white-label:

- `Low-ecommerce`: stack simples com `HTML + CSS + JavaScript` no frontend e `PHP` no backend.
- `High-ecommerce`: stack avançada com `Nuxt 3 + TypeScript` no frontend e `Node.js + TypeScript` no backend.

Cada modelo segue a mesma divisão:

- `frontend`: interface do cliente e painel inicial.
- `backend`: API e regras de negócio.
- `db`: schema SQL, seeds e documentação do banco.

## Próximos passos sugeridos

1. Definir gateway de pagamento.
2. Definir autenticação de clientes e administradores.
3. Escolher banco principal, como PostgreSQL ou MySQL.
4. Evoluir módulos de produtos, carrinho, pedidos e estoque.
